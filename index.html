Quickstart

Run Jazz++ in Seconds

Zero complex setup. Choose your operating system below to start making music.

The Linux AppImage bundles all required libraries (wxWidgets 3.2, libtiff, libasound, etc.) and is ready to run on any modern Linux distribution:

# 1. Make the AppImage executable chmod +x Jazz++-x86_64.AppImage
# 2. Launch Jazz++ ./Jazz++-x86_64.AppImage

💡 Tip: If you don't have a hardware MIDI synth connected, ensure a software synthesizer like FluidSynth is active (fluidsynth -a pulseaudio /usr/share/sounds/sf2/default.sf2). Jazz++ will detect and connect to it automatically.

The Windows package is completely portable and includes all required 64-bit runtime libraries:

  1. Download Jazz++-Windows-x64.zip.
  2. Extract the contents to any folder of your choice.
  3. Double-click jazz.exe to start. Windows default MIDI synthesizer (Microsoft GS Wavetable Synth) will be selected automatically.

Building Jazz++ from source is clean and straightforward with CMake and GCC/Clang or MSVC:

# Clone the repository git clone https://github.com/rajazahidi/Jazzplusplus.git cd Jazzplusplus
# Configure and build cmake -B build -DCMAKE_BUILD_TYPE=Release cmake --build build -j$(nproc)
# Run core unit tests ./build/jazz_tests
Release History

Changelog & Updates

Tracking the evolution and stability upgrades of the Jazz++ codebase.

v5.4.16 — Linux Playback Freeze Resolution & Synthesizer Auto-Binding Latest Release

  • Fixed GUI Freeze on Playback: Replaced legacy PCM audio device streaming (JZAlsaAudioPlayer) with pure ALSA MIDI Sequencer player (JZAlsaPlayer), eliminating thread lockups and buffer underruns on PipeWire and modern Linux sound servers.
  • Non-Blocking Event Polling: Opened ALSA sequencer with SND_SEQ_NONBLOCK and guarded real-time event reading with snd_seq_event_input_pending and an iteration cap, preventing GUI lockup.
  • ALSA Queue Start & Resuming: Proper handling of tick 0 playback (snd_seq_start_queue) versus resuming from measure offsets (snd_seq_continue_queue) with immediate stop drain.
  • Echo Loop Flooding Fix: Clamped lag offset in OutBreak() to prevent thousands of redundant echo events from saturating the ALSA ring buffer upon measure jumping.
  • Synthesizer Auto-Connect: Automatically scans available clients upon playback start and connects to active software/hardware synthesizers (FluidSynth, TiMidity) via subscribe_out.
  • proplist.cpp Null Safety: Guarded m_view pointer inside wxPropertyListDialog to ensure crash-free dynamic object instantiation.
  • Version Consistency: Synchronized version string 5.4.16 across CMakeLists.txt, configure.ac, and JazzPlusPlusVersion.h.

v5.4.15 — Track Bar Click-to-Play & Real-Time Queue Clock Sync

  • Track Bar Interactive Playback: Added click-to-play, click-to-pause, and drag-to-seek functionality on the measure ruler bar.
  • Kernel Queue Status Query: Query queue tick directly from ALSA kernel queue status to ensure smooth playback cursor motion without jitter.
  • CI Packaging: Automated standalone Linux AppImage packaging and Windows x64 MSVC packaging via GitHub Actions.
