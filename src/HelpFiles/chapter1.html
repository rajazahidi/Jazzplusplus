Chapter 1: Introduction & System Architecture

Jazz++ is a full-featured, open-source MIDI sequencer and Digital Audio Workstation (DAW). It combines traditional precision MIDI sequencing with high-performance digital audio recording, audio sample playback, and real-time DSP effects.

Originally designed as a cutting-edge sequencer for Linux and Windows, Jazz++ has been completely modernized in Version 6.0.0 by developer and maintainer Raja Zahidi. It features a modernized wxWidgets 3.x graphical interface, 64-bit audio processing, the flagship Virtual Session Band multi-instrument engine, and full cross-platform compatibility across Windows 10/11, modern Linux, and Apple Silicon / Intel macOS.

Core Features in Jazz++ 6.0.0

  • Multi-Track MIDI Sequencer: Unlimited MIDI tracks with independent channel assignments, program voices, velocity curves, volume, and pan controls.
  • Virtual Session Band Engine: RealTracks, RealDrums, and RealAudio dynamic backing band generating authentic walking bass, rhythm guitar, chord comping, and dynamic drum patterns across 10+ genres (Jazz, Bossa Nova, Blues, Funk, Rock, Latin).
  • Piano Roll Editor: Intuitive graphical note manipulation with snap-to-grid, micro-timing adjustment, multi-layer velocity handles, and event-curve drawing.
  • Integrated Audio DSP Suite: Studio-grade digital audio effects including Stereo Reverb, Tempo Delay, Chorus, Flanger, Overdrive/Distortion, and Parametric Equalizer.
  • Procedural Sound Generator: Real-time mathematical synthesis of electronic drum kits (808/909 kicks, snares, hats, claps) and sound design FX (risers, drops, noise sweeps).
  • Interactive Guitar Fretboard: Real-time fretboard visualization supporting standard and custom guitar tunings, chord voicing charts, and scale harmonizer.
  • Auto-Accompaniment & Harmony Browser: Intelligent chord scale analysis and automated rhythm generation for rapid song drafting.
  • Format Compatibility: Standard MIDI Files (.mid Format 0 and Format 1), Jazz++ Project Files (.jaz), and Uncompressed Audio (.wav).

Audio & MIDI Architecture

Jazz++ uses an asynchronous, multi-threaded audio architecture that separates the graphical user interface from the real-time MIDI sequencer and audio processing threads. This ensures jitter-free MIDI playback, precise note timing, and responsive controls even during heavy project workloads.
