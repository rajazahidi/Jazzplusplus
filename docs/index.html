True Acoustic Percussion

Acoustic RealDrums Engine Enjin RealDrums Akustik

Multi-velocity sample layering with smooth non-linear crossfading. Features intelligent Hi-Hat Choke Group (Closed HH cleanly chokes ringing Open HH) and round-robin micro-detuning (±12 cents) to eliminate machine-gun artificiality. Lapisan sampel pelbagai halaju dengan adunan bukan-linear licin. Dilengkapi logik Hi-Hat Choke Group (Closed HH mematikan Open HH) dan variasi mikro round-robin (±12 cents) bagi menghapuskan kesan statik dram tiruan.

WSOLA Time-Stretching
⏳

Elastic Audio & Chord Follower Audio Elastik & Pengikut Kord

Waveform Similarity Overlap-Add (WSOLA) engine seamlessly stretches audio loops from 50 to 240 BPM without pitch shifts. 4-point 3rd-order Hermite cubic resampling transposes phrases in real-time according to song chord progressions. Enjin WSOLA meregangkan gelung audio dari 50 hingga 240 BPM tanpa mengorbankan pic asli. Interpolasi kubik Hermite 4-titik membolehkan transposisi harmonik masa nyata mengikut perkembangan kord lagu secara lancar.

🎸

Resonance Modeling Suite Suite Pemodelan Resonans

Ubah petikan instrumen kepada rakaman mikrofon studio: resonans rongga Helmholtz 102Hz untuk badan gitar dreadnought, resonans simpati 88-tali piano grand konsert dengan basuhan pedal peredam (CC 64), serta ruang akustik binaural 3D.

Quickstart Guide Panduan Pantas

Run Jazz++ in Seconds Jalankan Jazz++ dalam Beberapa Saat

Zero complex dependencies. Choose your operating system below to start composing. Pemasangan mudah tanpa konfigurasi rumit. Pilih sistem operasi anda di bawah untuk memulakan gubahan muzik.

The Linux AppImage bundles all required libraries (wxWidgets 3.2, ALSA, libtiff) and runs out-of-the-box on Ubuntu, Debian, Fedora, Arch, and derivatives: Pakej Linux AppImage membundel semua pustaka yang diperlukan (wxWidgets 3.2, ALSA, libtiff) dan sedia dijalankan terus pada Ubuntu, Debian, Fedora, Arch, dan distro moden:

# 1. Make the AppImage executable chmod +x Jazz++-x86_64.AppImage
# 2. Launch Jazz++ ./Jazz++-x86_64.AppImage

💡 Tip: If you don't have a hardware synth connected, start FluidSynth (fluidsynth -a pulseaudio /usr/share/sounds/sf2/default.sf2). Jazz++ will detect and auto-bind to it immediately.

Native macOS release supporting Apple Silicon (M1/M2/M3/M4) and Intel with low-latency CoreMIDI and CoreAudio: Binaan asli macOS yang menyokong cip Apple Silicon (M1/M2/M3/M4) dan Intel dengan CoreMIDI & CoreAudio berlatensi rendah:

  1. Download Jazz++-macOS-arm64.zip.
  2. Double-click to extract the Jazz++.app bundle.
  3. Drag Jazz++.app into your /Applications folder.
  4. Launch Jazz++ from Spotlight or Launchpad. CoreMIDI endpoints will be enumerated automatically.

The Windows release is completely portable and includes all required 64-bit runtime libraries: Pakej Windows adalah sepenuhnya mudah alih (portable) dan mengandungi semua fail sokongan 64-bit:

  1. Download Jazz++-Windows-x64.zip.
  2. Extract the archive into any folder of your choice.
  3. Double-click jazz.exe to begin. The default Microsoft GS Wavetable Synth will be connected automatically.

Building Jazz++ from source is clean and straightforward with CMake and modern C++17: Membina Jazz++ daripada kod sumber adalah pantas dan bersih menggunakan CMake dan standard C++17:

# Clone the repository git clone https://github.com/rajazahidi/Jazzplusplus.git cd Jazzplusplus
# Configure and build cmake -B build -DCMAKE_BUILD_TYPE=Release cmake --build build -j$(nproc)
# Run core unit tests suite ./build/jazz_tests

v5.4.16 — Band-in-a-Box RealTracks, RealDrums & Studio RealAudio Architecture Latest Release

  • Band-in-a-Box RealDrums Engine: Multi-velocity studio acoustic sample playback replacing MIDI drum channel 10 with round-robin humanization and Hi-Hat Choke Group (Closed/Pedal HH cleanly damps ringing Open HH). Includes 4 acoustic kit profiles (Vintage Maple, Modern Birch, Jazz Club, Rock Stadium).
  • Band-in-a-Box RealTracks Engine: Elastic audio accompaniment phrase loops across 6 styles (Jazz Swing, Folk Ballad, Bossa Nova, Pop Rock, Blues Shuffle, Funk Groove). Features WSOLA elastic time-stretching (50–240 BPM without pitch shifts) and 4-point Hermite cubic chord-following pitch transposition.
  • RealInstrument & SoundFont Manager: Central hub coordinating RealDrums, RealTracks, and General MIDI SoundFonts (.sf2/.sf3) with physical modeling integration: 102Hz Helmholtz acoustic guitar body convolver, concert grand 88-string sympathetic resonance with damper wash (CC 64), and binaural 3D studio room acoustics.
  • Native macOS Apple Silicon Support: Full 64-bit arm64 native compilation with Apple Clang C++17, CoreMIDI and CoreAudio integration, standalone Jazz++.app bundle packaging, and GitHub Actions CI workflow.
  • Fixed Linux GUI Playback Freeze: Pure ALSA Sequencer engine implementation with non-blocking polling and kernel queue tick synchronization, eliminating legacy audio underruns on PipeWire and PulseAudio.
  • Synthesizer Auto-Discovery: Automatically enumerates active software/hardware synthesizers (FluidSynth, TiMidity) on playback start.
  • Interactive Ruler Bar Playback: Click directly on timeline ruler to seek and play instantly without audio stutter.
  • 100% Core Test Verification: 243 comprehensive automated unit tests running green across Linux (Ubuntu 24.04/22.04), AppImage, macOS arm64, and Windows MSVC x64.
