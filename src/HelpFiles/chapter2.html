Chapter 2: Installation and Setup

Jazz++ is distributed in ready-to-run packages for Windows, Linux, and macOS. Follow the instructions below for your operating system.

Windows 10 & 11 Installation

For Windows, two distribution options are provided on the official GitHub Releases page:

  • Windows Setup Installer (Jazz++-Windows-x64-Setup-v6.0.0.exe):

    The recommended installation method. Download and run the setup installer. It automatically guides you through selecting the installation path, creates Start Menu shortcuts, associates .jaz and .mid files, and installs all required 64-bit runtime libraries.

  • Portable ZIP Archive (Jazz++-Windows-x64.zip):

    A portable standalone package that requires no administrative privileges. Extract the archive into any folder (e.g. C:\Jazz++) and double-click jazz.exe to run.

Windows Defender / SmartScreen Notice: Because Jazz++ is an independent open-source project without expensive commercial certificate signatures, Windows SmartScreen may show a prompt ("Windows protected your PC"). Click "More info" and then "Run anyway" to proceed. The application contains zero telemetry or malware and the source code is 100% public.

Linux Installation

Jazz++ provides universal packages and source compilation options for Linux distributions:

  • Universal AppImage (Jazz++-x86_64.AppImage):

    Runs on almost all modern 64-bit Linux distributions without installing external packages:

    chmod +x Jazz++-x86_64.AppImage
    ./Jazz++-x86_64.AppImage
  • Building from Source:

    Jazz++ utilizes a standard CMake build pipeline. Install build essentials and wxWidgets development headers:

    sudo apt install cmake build-essential libasound2-dev libwxgtk3.2-dev
    cmake -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build -j$(nproc)

macOS Installation

Download Jazz++-macOS-arm64.zip. Unpack the zip file and drag Jazz++.app into your /Applications folder. On macOS, Jazz++ runs natively on Apple Silicon (M1/M2/M3/M4) as well as Intel-based Macs.

Configuring Audio & MIDI Devices

When you start Jazz++ for the first time, configure your MIDI and audio output settings:

  1. Navigate to Settings → MIDI Settings in the top menu.
  2. MIDI Output: Select your desired MIDI playback device:
    • Windows: Select "Microsoft GS Wavetable Synth", your USB MIDI interface, or a virtual cable to FluidSynth / VirtualMIDISynth.
    • Linux: Select the ALSA sequencer port corresponding to your hardware synth or software synth (TiMidity++ / FluidSynth).
    • macOS: Select the Apple CoreMIDI DLS Synth or connected USB MIDI interface.
  3. MIDI Input: If you have a USB MIDI keyboard or controller connected, select it as the active MIDI In device.
  4. Audio Settings: Go to Settings → Audio Settings to configure the audio sample rate (44100 Hz or 48000 Hz) and buffer size. A buffer of 256 or 512 samples provides ultra-low latency for recording and playback.
