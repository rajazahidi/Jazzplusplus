Chapter 5: Piano Window & Event Editing

The Piano Window (Piano Roll) provides high-precision graphical note editing. It allows you to inspect, compose, fine-tune, and edit individual MIDI notes and continuous controller events.

Piano Roll Navigation & Tools

  • Pitch Ruler: The vertical keyboard on the left displays notes from C-1 to G9. Clicking any key audibly auditions the instrument at that pitch.
  • Time Grid: The horizontal area displays measures subdivided into beats and ticks. The default resolution is 96 ticks per quarter note (standard MIDI resolution), allowing fine micro-timing.
  • Note Duration Selector: Buttons on the toolbar select note length for mouse entry: Whole note (1/1), Half note (1/2), Quarter note (1/4), Eighth note (1/8), Sixteenth note (1/16), Thirty-second note (1/32), and Triplet modifiers.
  • Snap-to-Grid: Constrains note movement and sizing to the selected rhythmic value. Toggle off for freehand micro-timing adjustments.

Note Manipulation

  • Insert Notes: Click with the left mouse button anywhere in the grid to place a note with the currently selected duration.
  • Move Notes: Click and drag the center of a note to move it in time (horizontal) or transpose pitch (vertical).
  • Resize Duration: Hover over the right edge of a note until the resize cursor appears, then drag to shorten or lengthen the note.
  • Delete Notes: Right-click a note or select it and press the Delete key.
  • Selection Box: Drag a box around multiple notes to select them for simultaneous moving, transposing, or deleting.
  • Velocity Editing: The lower velocity strip shows vertical stems representing each note's strike velocity (1 to 127). Drag the top of any stem to adjust dynamics from whisper-quiet pianissimo (pp) to commanding fortissimo (ff).

Continuous Controllers & Event Window

Beneath the note grid, Jazz++ provides specialized event lanes for continuous controller automation:

ControllerCC NumberDescription & Use
ModulationCC 1Vibrato depth and synth modulation curves
Main VolumeCC 7Track volume dynamics and automated volume fades
PanCC 10Stereo positioning (0 = Left, 64 = Center, 127 = Right)
ExpressionCC 11Sub-volume dynamics for expressive brass and strings swelling
Sustain PedalCC 64Damper pedal on/off switches (0 = Off, 127 = Sustained)
Pitch BendPitchWheelContinuous 14-bit pitch bending up or down
AftertouchChannel PressureExpressive pressure applied to keys after initial strike
Program ChangeVoice PatchSwitches instrument voice at specific points in the song

To draw controller automation, choose the controller type from the selector dropdown and draw curves freehand with the mouse.
